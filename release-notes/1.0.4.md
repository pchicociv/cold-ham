Cold Ham 1.0.4 corrige la acción «Abrir políticas» de 1.0.3, que podía dejar Chrome en una pestaña nueva sin abrir las políticas.

- Se sustituye la apertura externa por **Copiar chrome://policy** y **Copiar edge://policy**, en Permitidos y Diagnóstico. Chrome rechaza la dirección interna de políticas cuando se le pasa mediante la apertura externa usada anteriormente.
- Tras copiar, la aplicación indica que debes pegar la dirección en la barra de direcciones del navegador y pulsar Intro. Allí puedes pulsar **Volver a cargar las políticas** y recargar el sitio afectado, sin cerrar el navegador.
- Si el portapapeles está ocupado, se muestra la dirección para escribirla manualmente. El mensaje de copia se adapta al idioma seleccionado.
- Se elimina el lanzador defectuoso. Los botones no abren ventanas nuevas ni modifican políticas o perfiles del navegador.
- Se conservan todas las demás funciones de 1.0.3 y el formato de configuración 4: listas, horarios y ajustes no cambian.

Windows x64; incluye .NET. El instalador permite conservar el idioma actual. La recarga de políticas sigue siendo manual.
