Cold Ham 1.0.3 permite editar reglas existentes, investigar recursos que no cargan y comprobar el estado del bloqueo. También facilita la recarga de políticas sin cerrar Chrome o Edge.

- **Editar** en las listas de sitios bloqueados, permitidos y aplicaciones. En permitidos se puede ampliar o reducir la inclusión de subdominios. Los cambios se validan y confirman antes de guardarse; si falla el guardado se conserva la regla anterior.
- **Diagnóstico → Estado del bloqueo** muestra una instantánea de las reglas propias de hosts, políticas locales de Chrome/Edge, conflictos y recuperación pendiente. La comprobación no modifica esos archivos ni políticas.
- **Diagnóstico → Recursos que no cargan** analiza URLs o archivos HAR localmente, agrupa los dominios de solicitudes fallidas y permite añadir los seleccionados a la lista de permitidos. No se envía el análisis a ningún servicio ni se guardan cabeceras, cuerpos o URLs completas. Los errores de recursos también pueden tener causas ajenas al bloqueo.
- **Abrir políticas de Chrome / Edge** en Permitidos y Diagnóstico. Tras cambiar, activar o detener reglas, abre la página, pulsa **Volver a cargar las políticas / Reload policies** y recarga la pestaña afectada. La recarga normal permite mantener el navegador abierto. Los botones abren la página; la recarga sigue siendo manual y no se verifica automáticamente la navegación.
- Interfaz y ayuda en español e inglés, con desplazamiento en ventanas pequeñas. El actualizador aplaza el reinicio mientras hay un análisis de recursos pendiente.
- Se mantienen las correcciones de DevTools y la opción de permitir todos los subdominios incluidas en 1.0.2.

### Instalación y datos

Sal de Cold Ham desde la bandeja y ejecuta **ColdHam-win-Setup.exe**. Selecciona el idioma que ya utilizas para mantenerlo. El instalador conserva listas, horarios y configuración; esta versión mantiene el formato de datos 4. Ayuda debe mostrar **1.0.3**.

### Validación y distribución

57 pruebas automatizadas, incluidas persistencia, horarios, normalización, reversibilidad, edición, análisis local y diagnóstico sin escrituras. Interfaz comprobada mediante una ejecución WPF aislada en ambos idiomas a tamaño normal y mínimo. La navegación real y la recarga en los navegadores requieren comprobación manual.

Windows x64; incluye .NET. El instalador incorpora el selector de idioma y todavía no tiene firma Authenticode. El ZIP es la edición portátil; `.nupkg` y `releases.win.json` se usan para actualizaciones.
