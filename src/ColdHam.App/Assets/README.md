# Cold Ham icon

`ColdHam.png` is the original transparent artwork generated with the built-in image generation tool. `ColdHam.ico` contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel frames for Windows. Rebuild it with `./scripts/Build-Icon.ps1` using PowerShell on Windows; no extra packages are needed.

The ICO is used by the executable, WPF window, notification tray, and Velopack installer. The source PNG is kept for future artwork changes and is not shipped as a runtime dependency.

## Generation prompt

Use case: logo-brand
Asset type: Windows desktop application icon for Cold Ham, a local website and application distraction blocker.
Primary request: Create one polished compact icon: a stylized ham with a small icy cap, conveying the name Cold Ham. Simple memorable silhouette, thick clean dark outline, restrained flat illustration, large uncomplicated shapes readable at 16 and 32 pixels. Natural muted ham pink, ivory bone, cool pale ice blue. Centered, square composition with the symbol filling roughly 85% of the canvas. Transparent background outside the symbol. No words, letters, badge, surrounding tile, extra objects, tiny details, mockup, shadows outside the silhouette or watermark. Deliver only the single app icon.
